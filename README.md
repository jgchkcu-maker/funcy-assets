# Funcy Assets

Публичный каталог обоев и готовых тем FunPay Funcy. Исходный код расширения хранится отдельно.

## Добавить тему

1. Загрузите изображение в `wallpapers/`. Поддерживаются WebP, PNG, JPEG и GIF, максимум 5 МБ. Лучше использовать WebP и уникальное имя файла; при замене изображения меняйте имя, например `new-theme-v2.webp`.
2. Добавьте запись в массив `themes` файла `index.json`. Сохраните `version: 1` у каталога. `id` должен быть уникальным, состоять из строчных латинских букв, цифр и дефисов.
3. Сохраните изменения в ветке `main`.
4. В расширении откройте «Темы» и нажмите «Обновить каталог тем» (значок обновления). Каталог также обновляется при открытии раздела после истечения пяти минут.

```json
{
  "id": "new-theme",
  "name": "Новая тема",
  "meta": "Описание и цвета",
  "wallpaper": "wallpapers/new-theme-v1.webp",
  "theme": {
    "bgColor1": "#b3122e",
    "bgColor2": "#ff5c72",
    "containerBgColor": "#0d0e12",
    "textColor": "#eceef2",
    "linkColor": "#c9cfdb",
    "font": "Montserrat",
    "borderRadius": 12
  }
}
```

В `theme` можно использовать поля настроек темы, которые поддерживает расширение. Пропущенные поля получают значения по умолчанию. Обои задаются через `wallpaper`, а не `theme.bgImage`. Путь должен находиться внутри `wallpapers/`, без `..`, параметров URL и внешних адресов. Каталог поддерживает до 200 тем.

## Как загружаются обои

Расширение получает `index.json` при открытии раздела «Темы» и хранит последний успешно загруженный каталог локально. Превью загружаются лениво. При выборе темы изображение скачивается в черновик; после «Применить» оно сохраняется в браузере вместе с настройками, поэтому выбранный фон работает без сети и переносится при экспорте темы/настроек. Открытие каталога и выбор темы сами по себе не меняют тему сайта.
